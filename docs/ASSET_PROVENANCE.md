# Asset provenance

The meshes, skin weights, animations and embedded woven textures generated by
`tools/build_roster.py`, and geometry/materials constructed by `scripts/ring/venue.gd`,
were authored for this repository using mathematical geometry and keyframes.
No third-party model, commercial-game animation, scanned likeness, photograph,
voice sample or downloaded font was used in this overhaul. Character identity
labels and fictional stat/move data are inherited from the user's specification.
This statement is provenance, not a claim to a person's likeness/publicity rights.

The generated GLB metadata calls the visual designs original stylized ring
interpretations. Reference-accurate resemblance has not been verified. Review
rights and branding before any public/commercial release.

Godot is an external engine. The source download does not redistribute its binary
or font files. Use an official installed engine to open the project.
